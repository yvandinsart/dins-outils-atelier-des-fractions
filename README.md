## Déploiement GitHub Pages

1. Créez un dépôt GitHub.
2. Téléversez tous les fichiers à la racine.
3. Activez GitHub Pages (Settings > Pages > Deploy from a branch > main / root).
4. L'application sera accessible via GitHub Pages.
